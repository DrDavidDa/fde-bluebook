【开场】那道没有标准答案的题

一位候选人在 Palantir 系公司的终面被问到：

"假设你明天进驻一家医院。院长说'我们要用 AI 提升效率'，信息科主任说'系统不能动'，护士长说'别给我们添乱'。你第一周做什么？"

候选人开始讲技术方案。面试官打断："你还没问问题。"

FDE 面试考的不是答案，是你先问什么。

【场 1】三轮面试的隐藏考纲

三轮面试 · 隐藏考纲
技术轮
你真能独立造出来吗？关键词：evals 思维
现场模拟轮
45 分钟进场计划：问题质量占 40%
客户沟通轮
压力题暗线：单独扔进客户现场，公司是增值还是减值

第一轮：技术轮——"你真能独立造出来吗？"

  • 白板设计 RAG 系统：重点不在画图，在你主动问什么——数据量级？更新频率？延迟要求？不追问就开画的，直接挂；
  • 手写数据管道代码：看工程直觉，不是语法；
  • "准确率从 92% 掉到 85%，怎么排查？"——考 evals 思维：数据漂移 → 检索召回 → 模型版本。没有评估思维的技术答案，全部零分。

第二轮：现场模拟轮——"你在混乱里能开路吗？"

  • 考题：一个模糊需求（"用 AI 提升客户满意度"），45 分钟后向"客户 CIO"汇报进场计划；
  • 评分权重：问题质量 40%（问了预算、数据、验收标准、上一个项目怎么死的吗）＞ 问题定义 30%（能否翻译成可测量的命题）＞ 方案节奏 20%（先 MVP 还是画大饼）＞ 表达气场 10%；
  • 气场只有一条标准：像顾问，还是像乙方。

第三轮：客户沟通轮——"你能代表公司坐在客户对面吗？"

  • "别人的 demo 比你的好看"——把话题从 demo 效果拉回验收标准和真实数据；
  • "CEO 要砍预算 30%"——保数据工程和 evals，砍界面美化，考你对价值链的理解；
  • 角色扮演：向不懂技术的业务负责人解释为什么不能"直接接 ChatGPT"。

三轮共同的暗线：把这个人单独扔进客户现场三个月，公司是增值还是减值。

【场 2】JD 解码术：读出字缝里的信息

招聘启事是加密的，解码规则：

JD 上写的实际是
"快节奏环境"没有流程，自己开路，也可能没人帮你
"与客户紧密合作"50% 以上时间在客户现场或时区里
"从 0 到 1"没有现成方案，包括没有文档
"支持销售周期"要陪售前去讲，半个售前
"推动产品反馈闭环"有砾石路机制，真 FDE
"负责端到端交付"出问题时没有别人可推

再用第 2 章的三问反查，真假 FDE 岗位一验便知。

【场 3】中美两个市场：不同的牌桌

  • 美国：岗位充足（100+ YC 公司 + 大厂），薪酬透明（$140K–600K+），强调全栈与创业气质，签证是主要门槛；
  • 中国：岗位名称混乱（解决方案工程师/交付专家/AI 应用工程师），但需求实打实在涨——私有化部署、国产模型适配、行业 know-how 三重要求，让合格的 FDE 比美国更稀缺。头部公司已开出对标研发的包。

差异化策略：与其卷"会用模型"，不如卷"懂一个行业 + 会私有化交付"——后者目前几乎没有竞争者。

【场 4】终极叩问：FDE 会被 Agent 取代吗

全书最后，正面回答这个问题。取代是分层发生的：

  • 正在被吃掉的部分：查数据、写胶水代码、生成文档、跑评估——可编码的部分，正在被 Agent 工具链快速自动化；
  • 反而更值钱的部分：判断哪个问题值得解决、在组织政治里开路、为结果签字——这些不是技术问题，是信任与责任问题。客户 CIO 敢把千万级项目托付给 Agent 吗？短期内，他只敢托付给人。

McGrew 的洞察：FDE 本质上是"人形 Agent"。反过来也成立——Agent 越强大，驾驭 Agent 的 FDE 杠杆率越高。 一个 FDE 带一组 Agent，能交付过去五个人的活：岗位不消失，门槛水涨船高。

终章的答案不是安慰，是军规：

AI 不会取代 FDE。但会用 AI 的 FDE，会取代不用的。

你的护城河从来不是"会干活"，是"知道该干什么、并且敢为结果签字"。
